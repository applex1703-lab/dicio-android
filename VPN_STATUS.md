# Статус запроса VPN

Явная команда или выбор карточки отправляют запрос без ожидания озвучки и без подтверждения соединения. На домашнем экране Dicio доступен текст последнего отправленного запроса: для Happ он не подтверждает подключение, а для неподдерживаемого клиента означает только отправку запроса на открытие приложения. Проверить состояние нужно в самом VPN-приложении. Подключение другого VPN может прервать текущий.

Обнаружение VPN ограничено видимостью пакетов и реализацией сервисов Android. Даже если найден только Happ, это не доказывает, что других VPN на устройстве нет; автоматически выбирается единственный **видимый** поддерживаемый кандидат.

Команды «выключи VPN» и «VPN отключи» отправляют запрос на отключение только при единственном видимом VPN — поддерживаемом Happ. При нескольких видимых VPN нужно явно назвать Happ; другие клиенты не открываются. Для Happ используется экспериментальный недокументированный адрес `happ://disconnect_without_ui`, наблюдавшийся в версии 4.8.0. Отправка запроса не подтверждает отключение; запасного запуска интерфейса и повторных попыток нет.

Статус содержит местное время отправки и хранится только в памяти процесса. Он удаляется кнопкой, при любом новом распознанном запросе (включая неоднозначные запросы VPN) или при завершении процесса. Это консервативный сброс: он действует и для запросов, не связанных с VPN. Статус не является мониторингом сети, не доказывает, что пользователь видел экран, и не озвучивается в фоне. Системный голосовой экран может закрыться при переходе во внешнее приложение; для просмотра статуса может потребоваться открыть домашний экран Dicio. Если запуск завершился ошибкой, статус отправленного запроса не создаётся. Неподдерживаемое приложение при открытии может само подключиться и прервать другой VPN.
